# myfin365

> 월세 카드결제·환급, 계약서 관리, AI 임대계약 검토를 한 곳에서 다루는 한국형 임대 금융 PWA 프로토타입(UI 목업).

임대인·임차인·자가거주민을 위한 모바일 금융 앱 콘셉트를 단일 HTML 파일로 구현한 인터랙티브 프로토타입입니다. 390×844 모바일 프레임 안에서 온보딩부터 결제·계약·리뷰 화면까지 흐름을 보여줍니다.

## 주요 기능

- **월세 카드결제** — 월세·관리비를 신용/체크카드로 결제하면 임대인 계좌로 입금. 무이자 할부 안내 포함.
- **월세 환급** — 월세 세액공제 기반 환급 신청 흐름(최대 590만원 안내).
- **계약서 관리** — 임대 계약 정보 등록 및 만기 관리.
- **AI 계약서 검토 / 투자 분석** — AI 임대계약 분석, 부동산 투자 분석 화면.
- **사용자 유형 선택** — 임대인 / 임차인 / 자가거주민에 맞춘 온보딩.
- **PWA** — 홈 화면 설치, 오프라인 캐시(Service Worker), 앱 바로가기(카드결제·환급 신청).

하단 5탭 내비게이션: 홈 · 결제 · 계약 · 리뷰 · 내정보.

## 기술 스택

- 바닐라 **HTML / CSS / JavaScript** (빌드 도구·프레임워크 없음)
- 단일 파일 구성: `index.html` 안에 마크업·스타일·스크립트 포함
- **PWA**: `manifest.json` + `sw.js`(캐시 우선 전략)
- 폰트: Noto Sans KR, Manrope (Google Fonts)

> 백엔드·데이터베이스 없이 동작하는 UI 프로토타입입니다. 결제·환급 등은 실제 처리 없이 화면 흐름만 시연합니다.

## 로컬 실행

별도 빌드가 필요 없습니다. 정적 서버로 띄우면 됩니다(Service Worker는 `http://`/`https://`에서 동작).

```bash
# 저장소 클론 후 디렉터리에서
python -m http.server 8000
# 브라우저에서 http://localhost:8000/index.html 접속
```

`index.html`을 파일로 직접 열어도 화면은 보이지만, PWA 설치·오프라인 캐시 기능은 정적 서버에서만 동작합니다.

## 파일 구성

| 파일 | 설명 |
|------|------|
| `index.html` | 앱 전체(화면·스타일·로직) |
| `manifest.json` | PWA 매니페스트(이름·아이콘·바로가기) |
| `sw.js` | Service Worker(오프라인 캐시) |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |
